# Chiffrement de bout en bout pour le service en ligne

Le serveur ne stockera que des données illisibles pour lui, et les changements fusionneront sur les appareils. Pour une application financière, c'est un argument de confiance fort, cohérent avec le coffre des cartes.

## Consequences

Sans code de récupération, un mot de passe oublié rend les données en ligne irrécupérables. Le serveur ne peut ni filtrer ni analyser le contenu. Toute IA en ligne devra envoyer explicitement les données concernées, avec l'accord de l'utilisateur.
