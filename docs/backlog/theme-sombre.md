# Thème sombre

La V1 est conçue en thème clair. Le thème sombre sera ajouté ensuite, sur toutes les maquettes puis dans l'application, avec un choix clair, sombre ou réglage du système.

Palette de départ, issue des maquettes écartées pour l'instant :

| Rôle | Valeur |
|---|---|
| Fond | `#0E1320` |
| Surface | `#181F31` |
| Barre de navigation | `#232C43` |
| Texte | `#EEF1F7` |
| Texte secondaire | `#A4AEC2` |
| Accent (texte, jauges) | `#5EEAB5` |
| Piste des jauges | `#2B3550` |
| Retard ou dépassement | `#FFB4A2` |

Piste retenue pour la barre du bas : flottante et sombre, icônes claires (`#AEB6C6`), onglet actif en menthe (`#5EEAB5`), avec une ombre marquée. Elle a été proposée en thème clair (option C) et gardée pour le thème sombre.
