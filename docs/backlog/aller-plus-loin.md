# Aller plus loin avec l'argent des utilisateurs

Vision du propriétaire, notée le 23 novembre 2026, pour après la V1 : aider vraiment à mieux gérer son argent, pays par pays.

## Idées

- **Remboursements automatisés** via les API de mobile money (M-Pesa, Airtel Money, Orange Money), avec des rappels dans ce sens.
- **Suivi des emprunts bancaires** : échéancier, intérêts, capital restant.
- **Taxes et impôts** : aider à calculer ce qu'on doit à l'État, selon le pays ; d'abord la RDC, puis peut-être la Belgique et le Canada, petit à petit.
- **Présentation des emprunts** : l'utilisateur choisit comment un emprunt ou une dette apparaît dans ses finances (déjà un réglage d'affichage en phase 5 ; à approfondir).

## Points d'attention

- Les API de mobile money supposent une connexion et des comptes chez les opérateurs : c'est un changement par rapport à « hors ligne par défaut » (voir les ADR sur la synchronisation).
- Les règles fiscales changent chaque année et engagent une responsabilité : sources officielles et avertissements nécessaires.
