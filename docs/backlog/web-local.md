# Accès web local et visualisation sur ordinateur

Consulter ses données depuis un navigateur, le téléphone servant de serveur sur le réseau local. L'application doit rester ouverte pendant l'accès, ce qui est accepté, et le comportement sera le même sur Android et iOS.

Variante prévue : partager ses données en lecture seule pour les visualiser sur un ordinateur ou un autre appareil.

À décider : modification ou lecture seule depuis le web, appairage du navigateur (code ou QR), chiffrement du trafic local. Le coffre des cartes reste exclu.
