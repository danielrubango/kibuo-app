# Offre payante

L'usage offline reste gratuit à vie. L'abonnement ou la vente porteront sur les services en ligne : sauvegarde cloud, synchronisation entre appareils et, le cas échéant, IA.

À décider : prix par pays, abonnement ou achat unique, période d'essai, moyens de paiement selon les marchés.
