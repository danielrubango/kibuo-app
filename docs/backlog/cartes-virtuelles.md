# Coffre des cartes virtuelles

Enregistrer ses cartes virtuelles pour les retrouver et copier leurs informations quand un service en ligne les demande. Numéro, expiration et CVV sont gardés dans un coffre séparé.

Règles retenues :

- biométrie à chaque affichage ou copie ;
- copie marquée comme sensible et presse-papiers effacé après 30 secondes ;
- captures d'écran bloquées ;
- exclusion de la version web locale ;
- sauvegarde uniquement avec un mot de passe ;
- cloud uniquement avec chiffrement de bout en bout.

Avant le cloud : vérification juridique, notamment sur l'applicabilité de la norme PCI DSS.
