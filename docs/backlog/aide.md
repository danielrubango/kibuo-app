# Aide et support

Les points à expliquer dans l'aide de kibuo (planche `AideSupport`), notés au fil des décisions.

- **Changer le mot de passe des sauvegardes** (demandé par le propriétaire le 25 novembre 2026) : les sauvegardes déjà faites gardent l'ancien mot de passe et ne s'ouvrent pas avec le nouveau. L'utilisateur doit le comprendre avant de changer ; pour l'instant la feuille ne le dit pas, l'aide le dira.
