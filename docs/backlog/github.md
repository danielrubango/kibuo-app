# Porter le suivi sur GitHub

Dépôt privé sur le compte personnel du propriétaire, à créer rapidement.

| Local | GitHub |
|---|---|
| Phases de `docs/ROADMAP.md` | Milestones |
| Cases non cochées | Issues, rattachées à leur milestone |
| Fichiers de `docs/backlog/` | Issues, avec `title`, `milestone` et `labels` repris de l'en-tête |

Après le portage, GitHub devient la référence du suivi : `ROADMAP.md` ne garde que la vue d'ensemble, pour éviter deux sources de vérité, et le skill `/next-step` lit les issues.
