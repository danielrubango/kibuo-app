# Kibuo

Un compagnon simple pour mieux gérer son argent au quotidien : dépenses, revenus, budgets, dettes, créances et projets d'épargne.

Application Android en Flutter, totalement offline pour commencer. Le développement n'a pas encore démarré : le projet est en phase de cadrage et de design.
